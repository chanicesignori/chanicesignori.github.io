# chanicesignori.github.io

Portfolio site, built by GitHub Pages (Jekyll) straight from this repo. No build tools to install.

## Add a new write-up (about 5 minutes)

1. Open `TEMPLATE.md` and copy everything.
2. In the `_work` folder, choose **Add file → Create new file**. Name it like `my-new-post.md`.
3. Paste, fill in the lines at the top, write the body in Markdown.
4. **Commit changes.** In a minute or two it's live at `/work/my-new-post.html` and on the home page.

Works from the GitHub website or the GitHub phone app.

## Before you publish: the clean-up check

- [ ] No company or client names in case studies (say "a regional health system")
- [ ] No internal system names, hostnames, IPs, ticket numbers, or screenshots
- [ ] Numbers are ones you're allowed to share
- [ ] Your current employer is fine with you writing about the topic

## Where things live

| To change | Edit |
|---|---|
| A write-up | `_work/<name>.md` |
| Skills, certifications, "worked with" | `_data/skills.yml` |
| Email, LinkedIn, site description | `_config.yml` |
| Headline, intro, stats | `index.html` (top section) |
| Colors and fonts | `styles.css` |
| Headshot | `assets/headshot-cutout.png` |

## Hide a post without deleting it

Add `published: false` to its top section.
